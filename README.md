# Lingo-Trail
# Language Learning App

An interactive language learning app built.

## Features
- Choose from 15 languages.
- Vocabulary and Phrases sections presented as flashcards, with word, pronunciation guide, and translation
- Listen to each word/phrase spoken aloud using built-in text-to-speech
- Grammar tips section with short, useful notes for each language
- Quiz mode with multiple-choice questions to test what you've learned, with a live score
- Progress bar that tracks how much of each language's content you've viewed
- Progress is saved automatically in the browser (localStorage)

## Tech Used
- HTML, CSS, and JavaScript — all in a single `index.html` file, no build tools or dependencies required
- Browser's built-in Web Speech API for pronunciation playback

## How to Run
1. Download or clone this repository
2. Open `index.html` in any web browser
3. Pick a language, browse Vocabulary/Phrases/Grammar, and test yourself in the Quiz tab
